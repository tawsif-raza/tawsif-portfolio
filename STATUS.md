# Status

A short, honest log of what's actually been built — kept accurate rather than aspirational.

## What's built

Live on AWS Amplify at <https://main.dahjkchabvbri.amplifyapp.com/>.

- Core site: Hero, About, Projects, Skills, Services, Contact, Footer, plus supporting sections (Engineering Methodology, Architecture Showcase, Proof). Tech Stack, Current Focus and Closing CTA are no longer on the page; their files are still in `src/sections/`.
- A reusable 3D "living system" visualization (React Three Fiber), mounted in Methodology and Architecture with device-capability gating; on weaker devices it is left out and the surrounding text carries the content.
- Shared accessibility/perf hooks (`useReducedMotion`, `useInViewport`) backfilled across every animated component, replacing several independent one-off implementations.
- Build-time GitHub activity data (no client-side API calls).
- Contact form with real error handling (checks the response, shows a visible error state with a manual email fallback instead of silently redirecting or reporting false success).
- SEO/meta basics: OG/Twitter title + description, JSON-LD `Person` schema, robots.txt, favicon set from the TR monogram (SVG + ICO + PNG + apple-touch-icon, regenerated by `scripts/gen-logo-assets.py`), web manifest, dedicated OG share image.

## Known gaps / deliberately deferred

- No resume download yet — the button was removed rather than left pointing at a missing file. Re-add once a real PDF exists.
- No client testimonials yet — the section exists in code but renders nothing until real quotes are added (no fabricated placeholder content).
- No custom domain chosen. The URL-dependent tags (canonical, `og:url`/`og:image`, `twitter:url`/`twitter:image`), the JSON-LD `url` and `sitemap.xml` are still switched off — see "First deploy checklist" in README.md.
- Mobile/cross-browser testing has only been done via build/lint checks and dev-server console logs, not real devices or Safari/Firefox.

## Verification

- `npm run lint` — clean.
- `npm run build` — clean, no unexpected bundle regressions.
